# Getting Support

Thanks for using craboodle. This page lists where to go for different kinds of help.

## Questions and discussion

Open a [GitHub issue](https://github.com/bkudria/craboodle/issues) with the `question` label. Please search existing issues first.

## Bug reports

File a bug using the [bug report template](https://github.com/bkudria/craboodle/issues/new?template=bug_report.yml). Include the craboodle version, the scenario.yaml and checks.yaml, the command you ran, and the YAML output (or the stderr trace if it crashed before emitting results).

## Feature requests

Open a [new issue](https://github.com/bkudria/craboodle/issues/new) describing the use case, not just the proposed solution.

## Security vulnerabilities

Do **not** open a public issue. Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup, testing, and pull request guidelines.

## Commercial support

craboodle is an open-source project with no commercial support offering. There is no service-level agreement on issues or pull requests.
