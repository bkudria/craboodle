# Take Notes

Capture structured notes from a discussion into `notes.md`.

## Process

1. Read or accept the input (discussion text, meeting summary, raw notes).
2. Write `notes.md` with exactly three top-level sections, in this order:
   - `## Decisions` — choices that were settled.
   - `## Open questions` — things still to figure out.
   - `## Action items` — concrete next steps, with owner if named.
3. Use bulleted lists under each section. Leave a section empty (no bullets, just the heading and a blank line) if the input contains nothing for it — do not invent content.
